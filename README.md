# FinanceFlow Pro — versão 1.1 (demonstração recuperada)

Este repositório foi iniciado com a **demonstração HTML autônoma** do FinanceFlow Pro 1.1, recuperada de um arquivo anterior.

## Como executar

Abra `index.html` diretamente no navegador. Também é possível servi-lo com um servidor local estático.

## Escopo e limites

- Este pacote contém **somente a demonstração em HTML**, com CSS e JavaScript incorporados.
- O aplicativo usa dados locais no navegador e contém funcionalidades demonstrativas de gerenciamento financeiro.
- **Não inclui** o projeto fonte completo original, backend Node.js, banco SQLite, servidor API nem testes que possam ter existido em outro pacote.
- Não contém login real, conexão bancária, API financeira, pagamentos ou IA real.
- Não afirme que recursos ainda não implementados estão disponíveis.

## Próximos passos

1. Verifique se a pasta original ou `FinanceFlow_Pro_v1_1_Source.zip` está disponível em seu computador.
2. Se existir, compare o conteúdo e preserve versões e dados antes de substituí-lo.
3. Se não existir, use esta demonstração como referência visual e funcional **para reconstruir incrementalmente**, não como prova de recuperação do backend original.
4. Implemente testes antes de incorporar novas funcionalidades.

Este README documenta a origem e limitações da recuperação, não alega que o produto esteja pronto para produção.
